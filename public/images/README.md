# MOONY public-site image slots

The public UI is already wired to these production asset paths:

- `home-hero.webp` — validated homepage visual (intergenerational group around the traditional game)
- `mission-hero.webp` — validated mother / child / grandmother visual
- `approach-hero.webp` — validated group discussion visual
- `about-hero.webp` — validated About visual (group portrait / transmission)
- `community-hero.webp` — validated Entre Elles community visual

These files must be exported from the approved visual references and uploaded here as optimized WebP files. Do not replace them with generic stock photography.

Recommended export: 2400–2800 px wide, WebP quality 78–85, sRGB, target <= 600 KB when possible.
